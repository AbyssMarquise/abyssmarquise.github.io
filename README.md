# Portfolio de Camylle Michaud — version GitHub Pages

Cette version statique du portfolio peut être publiée directement avec GitHub Pages. Elle ne nécessite ni installation, ni compilation, ni abonnement payant.

## Publication

1. Créer un dépôt public nommé `VOTRE-NOM-UTILISATEUR.github.io`.
2. Téléverser à la racine du dépôt le contenu de ce dossier : `index.html`, `style.css`, `favicon.svg`, `.nojekyll` et le dossier `assets`.
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Sous **Build and deployment**, sélectionner **Deploy from a branch**.
5. Choisir la branche **main**, le dossier **/(root)**, puis enregistrer.
6. Ouvrir `https://VOTRE-NOM-UTILISATEUR.github.io` après la publication.

Important : il faut téléverser le contenu du dossier, pas uniquement le fichier ZIP.

## Personnalisation

- Les textes et les liens se trouvent dans `index.html`.
- Les couleurs, la typographie et la mise en page se trouvent dans `style.css`.
- Le vert principal est `#066460`.
- Les images sont dans `assets`.
